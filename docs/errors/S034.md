# S034: Only an owner can replace what it holds

Topic: 4.6 Inputs and outputs

Assigning to a binding that owns something frees what it held first. An input borrows what it's given, and its caller still owns and frees it, so the input can't replace it. A binder in a match borrows its subject the same way.

An input that should take its argument over is declared `unscoped`, and one that should replace its caller's value is a view, `peek mut`.

## Wrong

```cherimoya
let (xs :: mut arr[int]) -> renew -> () { xs <- arr[int]([1, 2]); }
```

## Fixed

```cherimoya
let (xs :: peek mut arr[int]) -> renew -> () { xs <- arr[int]([1, 2]); }
```
