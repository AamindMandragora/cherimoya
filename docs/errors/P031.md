# P031: Generic parameters are written '[T :: Bound <- Fallback]'

Topic: 5.4 Generics

A function's or a type's generic parameters go in brackets: each a name, its bounds after `::` joined with `&`, and a default after `<-`, separated by commas.

## Wrong

```cherimoya
let [T :: Ord, 2] (a :: T, b :: T) -> max -> (m :: T) { a -| }
```

## Fixed

```cherimoya
let [T :: Ord] (a :: T, b :: T) -> max -> (m :: T) { a -| }
```
