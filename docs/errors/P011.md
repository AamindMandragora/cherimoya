# P011: A comprehension's head is a plain expression

Topic: 2.7 Comprehensions

The head of a comprehension, before the `:`, is any expression. A name with `<-`, an exclusivity marker, or `...` there belongs to a pack or a range, not to a comprehension.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [a <- x : x > 0] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [x : x > 0] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
