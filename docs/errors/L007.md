# L007: Every character outside a literal has to start a token

Topic: 1 Lexical structure

Outside a literal, every character has to start a name, a number, a literal, an operator, or punctuation. A non-ASCII character outside a literal is an error, and so is any character no token starts with. Reading carries on past each one, so the rest of the file is still checked.

## Wrong

```cherimoya
let pi <- π;
```

## Fixed

```cherimoya
let pi <- 3.14;
```
