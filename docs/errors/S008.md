# S008: Every input and output has a type

Topic: 6.1 Signatures

A function's signature is the contract its callers rely on, so every input and every output has its type written out, and none is inferred from the body.

## Wrong

```cherimoya
let (n) -> twice -> (r :: int) { n * 2 -| }
```

## Fixed

```cherimoya
let (n :: int) -> twice -> (r :: int) { n * 2 -| }
```
