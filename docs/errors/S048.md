# S048: Only a signed or wrapping integer can be negated

Topic: 5.5 Integers

Negating a trapping unsigned value overflows for everything but 0, so prefix `-` takes only signed and wrapping integers. The error suggests the signed or the wrapping type.

## Wrong

```cherimoya
let (x :: i32u) -> f -> (r :: i32u) { -x -| }
```

## Fixed

```cherimoya
let (x :: i32uw) -> f -> (r :: i32uw) { -x -| }
```
