# S070: An empty array's type is known

Topic: 2.10 Packs, tuples, and records

A pack takes its element type from its elements, or from where it goes. An empty pack has no elements, so its type has to come from where it goes, like an annotation.

## Wrong

```cherimoya
let () -> f -> (r :: i64u) { let xs <- []; xs.len() -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: i64u) { let xs :: arr[0, int] <- []; xs.len() -| }
```
