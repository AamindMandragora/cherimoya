# N035: Packs whose elements have different types aren't supported yet

Topic: 2.10 Packs, tuples, and records

A homogeneous pack is an array and a tuple at once, and a heterogeneous pack like `[1, 2.0]` is a tuple only. Tuples aren't built yet, so every element of a pack has to have one type for now.

## Wrong

```cherimoya
let () -> f -> (r :: i64u) { let xs <- [1, true]; xs.len() -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: i64u) { let xs <- [1, 2]; xs.len() -| }
```
