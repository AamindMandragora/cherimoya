# N009: Generic functions aren't supported yet

Topic: 5.4 Generics

A generic function, `let [T :: Ord] (a :: T, b :: T) -> max -> (m :: T)`, will take types and values known while compiling, and every concrete use will make its own copy of it. Generics are built on comptime, which isn't built yet.

Until then, a function is written for the types it's used with, once for each.

## Wrong

```cherimoya
let [T] (a :: int, b :: int) -> larger -> (m :: int) {
    match {
        (a > b) -> { a -| }
        _       -> { b -| }
    } -|
}
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> larger -> (m :: int) {
    match {
        (a > b) -> { a -| }
        _       -> { b -| }
    } -|
}
```
