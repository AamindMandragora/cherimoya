# S049: Both sides of an operator have the same type

Topic: 5.5 Integers

Integers of different types never mix, and neither do floats, so `x + y` with an `i8` and an `i16` is an error, with a note on each side's type. Conversions are explicit, so what each side becomes is always written.

## Wrong

```cherimoya
let (x :: i8, y :: i16) -> f -> (r :: i16) { x + y -| }
```

## Fixed

```cherimoya
let (x :: i8, y :: i16) -> f -> (r :: i16) { i16(x) + y -| }
```
