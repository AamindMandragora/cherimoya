# P021: A pattern is a literal, a name, _, a variant, a pack, a range, or a set-builder

Topic: 3.6 `match`

Every pattern is written like an expression, and then read as a pattern. Only literals (including negated numbers), `_`, binders, variants with nested patterns, packs, ranges, and set-builders are patterns, so another expression, like an operation, can't be one.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (n) {
        n + 1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
