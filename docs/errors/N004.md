# N004: A mode anywhere but on an input, a binding, or an output isn't supported yet

Topic: 4.1 Modes

A mode, `peek` or `unscoped`, says how a binding relates to its memory, so today it goes only at the top of an input's, a binding's, or an output's type. A mode inside another type, like an array of views, will make that type peek-like, which is built with views inside packs and records.

Until then, the mode goes on the whole value: a view of the array, rather than an array of views.

## Wrong

```cherimoya
let (xs :: arr[3, peek int]) -> first -> (x :: int) { xs[0] -| }
```

## Fixed

```cherimoya
let (xs :: peek arr[3, int]) -> first -> (x :: int) { xs[0] -| }
```
