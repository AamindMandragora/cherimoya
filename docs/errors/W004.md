# W004: A .toya file with no test runs nothing

Topic: 12 Tests

A `.toya` file is for tests, so one with no test in it runs nothing, which is a warning. A test is a function marked `@test`.

## Wrong

```cherimoya toya
let () -> adds -> () { assert (1 + 1 = 2); }
```

## Fixed

```cherimoya toya
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```
