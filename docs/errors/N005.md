# N005: Tuple types aren't supported yet

Topic: 2.10 Packs, tuples, and records

A tuple type, `[int, f64]`, will hold values of different types side by side, the way a heterogeneous pack does, with each element reached by an index known when the program compiles.

Tuples aren't built yet, so the values are passed separately, or as an array when they share a type.

## Wrong

```cherimoya
let (t :: [int, f64]) -> first -> (x :: int) { t[0] -| }
```

## Fixed

```cherimoya
let (a :: int, b :: f64) -> first -> (x :: int) { a -| }
```
