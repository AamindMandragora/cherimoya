# N031: Types as values aren't supported yet

Topic: 7 Comptime

A type will be a value known while compiling, which can be bound and passed like any other, and that's what generics are built on. That waits for comptime.

Until then, a type is only written where one goes: after `::`, or called to convert a value, like `int(n)`.

## Wrong

```cherimoya
let (n :: i32) -> widen -> (r :: int) {
    let target <- int;
    target(n) -|
}
```

## Fixed

```cherimoya
let (n :: i32) -> widen -> (r :: int) {
    int(n) -|
}
```
