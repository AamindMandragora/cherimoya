# P023: A binding has an initializer

Topic: 3.2 Bindings

Every binding needs an initializer, and `_` explicitly means uninitialized, so a binding left uninitialized says so. A missing initializer gets a fix that adds `<- _`.

## Wrong

```cherimoya
let x :: int;
```

## Fixed

```cherimoya
let x :: int <- 0;
```
