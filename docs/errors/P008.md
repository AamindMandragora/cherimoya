# P008: An exclusivity marker on a negative bound is written '< -1', not '<-1'

Topic: 2.6 Ranges

Maximal munch reads `<-1` as the flow token `<-` and then `1`, never as `<` and `-1`. So a marker on a negative bound is written with a space, `< -1`.

## Wrong

```cherimoya
let (n :: int) -> sign -> (r :: int) {
    match (n) {
        [-9, ..., <-1] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> sign -> (r :: int) {
    match (n) {
        [-9, ..., < -1] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
