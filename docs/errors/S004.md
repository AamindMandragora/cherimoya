# S004: An array's size has to be known when the program compiles

Topic: 4.3 Arrays and handles

A fixed array, `arr[N, T]`, holds its elements inline, so its size is part of its type and has to be known when the program compiles. It can be an integer literal, or an immutable binding whose initializer folds to one, like `let N <- 2 + 1;`.

A `mut` binding can change while the program runs, so it can't be a size. A length known only at run time makes an array on the heap instead, `arr[n, int](0)`.

## Wrong

```cherimoya
let size :: mut <- 3;
let (xs :: arr[size, int]) -> first -> (x :: int) { xs[0] -| }
```

## Fixed

```cherimoya
let size <- 3;
let (xs :: arr[size, int]) -> first -> (x :: int) { xs[0] -| }
```
