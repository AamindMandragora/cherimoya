# P051: A field access is written 'value.field'

Topic: 2.10 Packs, tuples, and records

The dot is for what a type owns, fields and methods, and for module paths, and a name always follows it. Fields are accessed by name with `.x`, and by position with `[0]`.

## Wrong

```cherimoya
let xs <- [1, 2];
let first <- xs.0;
```

## Fixed

```cherimoya
let xs <- [1, 2];
let first <- xs[0];
```
