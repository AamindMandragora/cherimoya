# S037: A nested function can't use the locals of the function around it

Topic: 2.12 Closures

A named function inside a body doesn't capture, so it can't use the enclosing function's locals. A closure captures what it uses, listed in brackets, or the nested function takes the value as an input.

## Wrong

```cherimoya
let (n :: int) -> outer -> (r :: int) {
    let () -> inner -> (r :: int) { n -| }
    inner() -|
}
```

## Fixed

```cherimoya
let (n :: int) -> outer -> (r :: int) {
    let (m :: int) -> inner -> (r :: int) { m -| }
    inner(n) -|
}
```
