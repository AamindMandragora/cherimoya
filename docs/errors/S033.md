# S033: A match covers every value when a missing case would matter

Topic: 3.6 `match`

An incomplete match leaves a case unhandled, which is real harm, so it's an error, with a fix that adds `_ -> { }`. A match on a number, a character, a `boolf`, or an array always needs a catch-all, and so does any match whose value is used. `true` and `false` together cover a `bool`, and a subjectless match whose value is void, like the guard form, needs none.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        0 -> { 1 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        0 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
