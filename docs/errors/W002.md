# W002: A string pattern of another length than a fixed subject never matches

Topic: 3.6 `match`

A string pattern matches an array of bytes of the same length and bytes. A fixed array's length is part of its type, so a string of another length can never match it, and its arm never runs.

## Wrong

```cherimoya
let (s :: arr[3, i8u]) -> isCat -> (r :: bool) {
    match (s) {
        "ca" -> { true -| }
        _ -> { false -| }
    } -|
}
```

## Fixed

```cherimoya
let (s :: arr[3, i8u]) -> isCat -> (r :: bool) {
    match (s) {
        "cat" -> { true -| }
        _ -> { false -| }
    } -|
}
```
