# P012: A comprehension is written '[head : clauses]'

Topic: 2.7 Comprehensions

A comprehension is its head, a `:`, and its clauses joined with `&&`, all in brackets and closed with `]`.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [x : x > 0 1] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [x : x > 0] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
