# S041: A boolf literal has to be from 0 to 1

Topic: 5.9 `boolf`

A `boolf` is a fuzzy truth value from 0 to 1, so a number literal becomes one only when it's in that range. A literal is never quietly clamped, since that would hide the mistake.

## Wrong

```cherimoya
let () -> f -> (r :: boolf) { 1.5 -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: boolf) { 0.5 -| }
```
