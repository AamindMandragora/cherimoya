# S061: An array on the heap is made from a fixed array or a string

Topic: 4.3 Arrays and handles

`arr[T](xs)` puts a fixed array's elements on the heap, and given another kind of string it converts it into a new array. Anything else has no elements to make it from.

## Wrong

```cherimoya
let () -> f -> (r :: i64u) { arr[int](true).len() -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: i64u) { arr[int]([1, 2]).len() -| }
```
