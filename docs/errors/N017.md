# N017: Extra operators aren't supported yet

Topic: 2.13 Extra operators

The extra operators, like `**` and `<+>`, have no built-in meaning, so a program will give them one by defining them, the way it overloads a built-in operator. That waits for operator overloading.

Until then, the operation is written out, or as a function with a name.

## Wrong

```cherimoya
let (x :: int) -> square -> (r :: int) { x ** 2 -| }
```

## Fixed

```cherimoya
let (x :: int) -> square -> (r :: int) { x * x -| }
```
