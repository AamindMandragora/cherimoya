# S082: Names in one scope are distinct

Topic: 3.2 Bindings

An inner scope may shadow an outer name, but one scope can't declare a name twice, since every use after both would be ambiguous. The error has a note at the first declaration.

## Wrong

```cherimoya
let () -> f -> (r :: int) { let x <- 1; let x <- 2; x -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: int) { let x <- 1; let y <- 2; x + y -| }
```
