# P026: A match's equality is '=' or '=='

Topic: 3.6 `match`

A match's patterns compare with deep equality by default. `match (=, x)` compares shallowly, and `match (==, x)` spells the default. Those are the only two equalities a match takes.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (<, n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (=, n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
