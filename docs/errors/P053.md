# P053: Operators on one level with different or no associativity need parentheses to mix

Topic: 2.1 Precedence

Two operators on the same level next to each other need parentheses when their associativities differ or either one is non-associative, so `a = b = c` and `a <=> b <= 0` are errors. The error offers both groupings as fixes.

## Wrong

```cherimoya
let a <- 1;
let b <- 2;
let x <- a = b = true;
```

## Fixed

```cherimoya
let a <- 1;
let b <- 2;
let x <- (a = b) = true;
```
