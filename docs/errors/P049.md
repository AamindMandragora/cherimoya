# P049: A closure's captures are unnamed

Topic: 2.12 Closures

Owning captures are listed in a pack before a closure's inputs, `[factor] (x) -> { ... }`, and each one is a value the closure copies or moves in under its own name, so a capture takes no `name <-`.

## Wrong

```cherimoya
let k <- 2;
let scale <- [n <- k] (x :: int) -> (r :: int) { x * n -| };
```

## Fixed

```cherimoya
let k <- 2;
let scale <- [k] (x :: int) -> (r :: int) { x * k -| };
```
