# S076: Only a function is called

Topic: 2.2 Calls and methods

A call's callee has to be a function, called by its name. A binding that holds a value isn't one.

## Wrong

```cherimoya
let () -> f -> (r :: int) { let g <- 1; g(2) -| }
```

## Fixed

```cherimoya
let (x :: int) -> g -> (r :: int) { x -| }
let () -> f -> (r :: int) { g(2) -| }
```
