# N021: Functions as values aren't supported yet

Topic: 2.12 Closures

A function's name without a call will be the function as a value, which can be bound, passed, and called later, the way a closure is. Both follow the `Fn` protocol, which waits for protocols.

Until then, a function is only ever called by its name.

## Wrong

```cherimoya
let (n :: int) -> double -> (r :: int) { n * 2 -| }
let (n :: int) -> quadruple -> (r :: int) {
    let step <- double;
    step(step(n)) -|
}
```

## Fixed

```cherimoya
let (n :: int) -> double -> (r :: int) { n * 2 -| }
let (n :: int) -> quadruple -> (r :: int) {
    double(double(n)) -|
}
```
