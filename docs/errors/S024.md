# S024: A top-level binding can't be unscoped

Topic: 4.1 Modes

An `unscoped` binding owns heap memory it has to move on before its scope ends. A top-level binding is a global every function can use, so it can never be moved, and it's freed when the program ends instead.

## Wrong

```cherimoya
let size :: mut i64u <- 2;
let xs :: unscoped arr[int] <- arr[size, int](0);
```

## Fixed

```cherimoya
let size :: mut i64u <- 2;
let xs :: arr[int] <- arr[size, int](0);
```
