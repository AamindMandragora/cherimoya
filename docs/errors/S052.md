# S052: A boolf becomes a bool only by a cutoff

Topic: 5.9 `boolf`

A `boolf` never becomes a `bool` by a conversion. Turning 0.7 into a yes or a no is a choice, so the program writes it, as a comparison: `x > 0.5`, or whatever cutoff it means.

## Wrong

```cherimoya
let (x :: boolf) -> f -> (r :: bool) { bool(x) -| }
```

## Fixed

```cherimoya
let (x :: boolf) -> f -> (r :: bool) { x > 0.5 -| }
```
