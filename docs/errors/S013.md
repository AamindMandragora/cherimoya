# S013: Only inputs have defaults

Topic: 6.1 Signatures

A default is what an input takes when a call leaves it out. An output is never passed by a call, it's produced by the function's yields, so a default on one would never be used.

## Wrong

```cherimoya
let () -> one -> (r :: int <- 1) { 1 -| }
```

## Fixed

```cherimoya
let () -> one -> (r :: int) { 1 -| }
```
