# S027: A function that yields an address yields one of its inputs'

Topic: 2.9 Indexing, slicing, dereference, views

An address is checked like a view: it can't outlive what it names, so two equal addresses always name the same memory. A function's own bindings are gone once it returns, so it can only yield addresses of places its caller gave it.

## Wrong

```cherimoya
let () -> where -> (r :: addr[int]) {
    let x <- 1;
    addr x -|
}
```

## Fixed

```cherimoya
let (x :: peek int) -> where -> (r :: addr[int]) { addr x -| }
```
