# L001: A number's digits have to be digits of its base

Topic: 1 Lexical structure

A number in base 2, 8, or 16 starts with `0b`, `0o`, or `0x`, and every digit after the prefix has to be a digit of that base. `_` separators can go anywhere in a run of digits.

A letter or digit the base doesn't have, right after the number, makes the rest of the word one mistake, so `0o78` and `123abc` are each reported once, instead of lexing as a number followed by a name.

## Wrong

```cherimoya
let x <- 0o78;
```

## Fixed

```cherimoya
let x <- 0o17;
```
