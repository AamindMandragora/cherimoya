# W001: A statement after one that always yields never runs

Topic: 3.4 Yields (`-|`)

A yield never continues, so statements after one, on every path, never run. That's a warning, since the program still runs correctly, with a fix that removes them, keeping any functions, which are hoisted.

## Wrong

```cherimoya
let () -> one -> (r :: int) {
    1 -|
    2 -|
}
```

## Fixed

```cherimoya
let () -> one -> (r :: int) {
    1 -|
}
```
