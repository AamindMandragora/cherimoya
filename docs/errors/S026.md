# S026: A function that yields a view yields a view of one of its inputs

Topic: 4.7 Peek rules

A view has no lifetime annotations. A function can yield one only when it's of one of its inputs that are views, since those belong to its caller, and anything else is gone once the function returns. Otherwise it yields a copy.

## Wrong

```cherimoya
let () -> one -> (r :: peek int) {
    let x <- 1;
    x -|
}
```

## Fixed

```cherimoya
let (x :: peek int) -> same -> (r :: peek int) { x -| }
```
