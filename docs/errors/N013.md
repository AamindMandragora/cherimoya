# N013: Pack patterns aren't supported yet

Topic: 3.6 `match`

A pack pattern, `[true, _]`, will match a pack element by element, which is how a decision table matches on several values at once, `match ([x, y])`.

Until then, a match without a subject tests the conditions together, one arm for each row of the table.

## Wrong

```cherimoya
let (a :: bool, b :: bool) -> both -> (r :: int) {
    match ([a, b]) {
        [true, true] -> { 1 -| }
        _            -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (a :: bool, b :: bool) -> both -> (r :: int) {
    match {
        (a && b) -> { 1 -| }
        _        -> { 0 -| }
    } -|
}
```
