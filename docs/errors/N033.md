# N033: Moving out of an element or a pointer isn't built yet

Topic: 4.5 Ownership and moves

Moving out of an element, `let p <- ps[0];`, would leave a hole the array frees. `take`, which marks it unwritten, will do it, and until then an owning element can be used in place, or viewed.

## Wrong

```cherimoya
let (ps :: arr[ptr[int]]) -> first -> (r :: int) {
    let p <- ps[0];
    p[] -|
}
```

## Fixed

```cherimoya
let (ps :: arr[ptr[int]]) -> first -> (r :: int) {
    let p :: peek <- ps[0];
    p[] -|
}
```
