# P037: An import names its module as 'import [items] <- module.path;'

Topic: 8 Modules and the standard library

An import lists its items, then `<-` and the module's path, with `.` between directories: `import [Allocator] <- std.mem;`.

## Wrong

```cherimoya
import [Allocator] from std.mem;
```

## Fixed

```cherimoya
import [Allocator] <- std.mem;
```
