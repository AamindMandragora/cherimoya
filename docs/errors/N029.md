# N029: Comprehensions aren't supported yet

Topic: 2.7 Comprehensions

A comprehension, `[x * x : x <- xs]`, will be a lazy sequence of its head for each element its clauses bind and keep.

Until then, each element is computed by indexing, or written into an array by a loop.

## Wrong

```cherimoya
let (xs :: arr[3, int]) -> squares -> (r :: arr[3, int]) {
    [x * x : x <- xs] -|
}
```

## Fixed

```cherimoya
let (xs :: arr[3, int]) -> squares -> (r :: arr[3, int]) {
    [xs[0] * xs[0], xs[1] * xs[1], xs[2] * xs[2]] -|
}
```
