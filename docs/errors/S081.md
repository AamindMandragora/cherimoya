# S081: A .toya file has no start

Topic: 12 Tests

Tests go in `.toya` files, so they never ship in a program. A `.toya` file holds tests and the helpers they share, and has no `start`, since `cheri test` runs its tests instead.

## Wrong

```cherimoya toya
@test
let () -> adds -> () { assert (1 + 1 = 2); }
let () -> start -> (code :: int) { 0 -| }
```

## Fixed

```cherimoya toya
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```
