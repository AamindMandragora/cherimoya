# N023: Named packs aren't supported yet

Topic: 2.10 Packs, tuples, and records

A named pack, `[x <- 3, y <- 4]`, will be an anonymous record, typed structurally, whose fields are read by name or by position.

Records aren't built yet, so the pack is written without names, and its elements are read by position.

## Wrong

```cherimoya
let () -> origin -> (r :: int) {
    let p <- [x <- 3, y <- 4];
    p[0] -|
}
```

## Fixed

```cherimoya
let () -> origin -> (r :: int) {
    let p <- [3, 4];
    p[0] -|
}
```
