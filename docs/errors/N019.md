# N019: Type definitions aren't supported yet

Topic: 5.1 Definitions

A type definition, `type Name <- RHS;`, will make a newtype, a refinement, a product, a sum, an enum, or a protocol.

Until then, a value is held in the built-in type it would be defined over, like an `i64u` for a node's id.

## Wrong

```cherimoya
type NodeId <- i64u;
let (id :: i64u) -> next -> (r :: i64u) { id + 1 -| }
```

## Fixed

```cherimoya
let (id :: i64u) -> next -> (r :: i64u) { id + 1 -| }
```
