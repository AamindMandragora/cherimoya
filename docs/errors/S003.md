# S003: Only an owner can move what it holds

Topic: 4.5 Ownership and moves

A handle has one owner. An input borrows what it's given, so its caller still owns and frees it, and a binder in a match or a view only borrows what it reaches too. None of them can move what they hold on, since its owner would then free something that's gone.

An input that should take its argument over is declared `unscoped`, and then it owns it and can move it.

## Wrong

```cherimoya
let (xs :: arr[int]) -> keep -> (r :: arr[int]) { xs -| }
```

## Fixed

```cherimoya
let (xs :: unscoped arr[int]) -> keep -> (r :: arr[int]) { xs -| }
```
