# P032: A function is written 'let (inputs) -> name -> (outputs) { body }'

Topic: 6.1 Signatures

A function is `let`, its inputs in parentheses, `->`, its name, `->`, its outputs in parentheses, an optional `wit {obligations}`, and its body. The name slot holds an identifier or an overloadable operator, so a keyword can't be a function's name.

## Wrong

```cherimoya
let (a :: int) -> assert -> (r :: int) { a -| }
```

## Fixed

```cherimoya
let (a :: int) -> check -> (r :: int) { a -| }
```
