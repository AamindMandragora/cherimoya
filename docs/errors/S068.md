# S068: A method is called

Topic: 2.2 Calls and methods

A method is called on its object with parentheses, `xs.len()`. The dot without a call is for fields, so a method without its parentheses is an error, with a fix.

## Wrong

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { xs.len -| }
```

## Fixed

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { xs.len() -| }
```
