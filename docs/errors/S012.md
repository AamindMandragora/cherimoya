# S012: `traps` is a string and `timeout` a whole number of seconds above 0

Topic: 12 Tests

`traps` is the text the trap's message must hold, so it's a string. `timeout` is how many seconds the test gets before it fails, so it's a whole number above 0, written as an integer literal.

## Wrong

```cherimoya toya
@test(timeout <- 0)
let () -> quick -> () { assert (1 < 2); }
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```

## Fixed

```cherimoya toya
@test(timeout <- 5)
let () -> quick -> () { assert (1 < 2); }
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```
