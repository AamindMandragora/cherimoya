# S043: An integer literal has to fit in its type

Topic: 5.5 Integers

A literal takes the type its context expects, and has to fit there, for wrapping types too. A literal never wraps or truncates silently. A negated literal is checked whole, so `-128` fits in an `i8`.

## Wrong

```cherimoya
let () -> f -> (r :: i8) { 300 -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: i16) { 300 -| }
```
