# P042: A tuple type is written '[A, B]'

Topic: 2.10 Packs, tuples, and records

A tuple type is its element types in brackets, separated by commas, and closed with `]`.

## Wrong

```cherimoya
let (p :: [int, int) -> f -> () { }
```

## Fixed

```cherimoya
let (p :: [int, int]) -> f -> () { }
```
