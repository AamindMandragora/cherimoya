# P041: A record type is written '[name :: Type, name :: Type]'

Topic: 2.10 Packs, tuples, and records

A record type is its fields in brackets, each a name, `::`, and a type, separated by commas.

## Wrong

```cherimoya
let (p :: [x :: int, y: int]) -> f -> () { }
```

## Fixed

```cherimoya
let (p :: [x :: int, y :: int]) -> f -> () { }
```
