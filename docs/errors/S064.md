# S064: Unnamed arguments come before named ones

Topic: 2.2 Calls and methods

Unnamed arguments go to the inputs in order, then named ones go to the inputs they name. Every unnamed argument comes before every named one, so where an unnamed one goes never depends on the names around it.

## Wrong

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(a <- 1, 2) -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(a <- 1, b <- 2) -| }
```
