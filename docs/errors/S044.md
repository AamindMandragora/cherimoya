# S044: A float literal has to fit in its type

Topic: 5.6 Floats

A float literal past its type's largest finite value is an error, so a literal never quietly rounds to the largest value or to infinity.

## Wrong

```cherimoya
let () -> f -> (r :: f16) { 65536.0 -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: f32) { 65536.0 -| }
```
