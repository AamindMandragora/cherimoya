# N022: Fields aren't supported yet

Topic: 2.10 Packs, tuples, and records

A field, `p.x`, will read a value a record holds by its name. Fields come with records.

Until then, a value made of parts is an array, whose parts are read by position.

## Wrong

```cherimoya
let (p :: arr[2, int]) -> width -> (r :: int) { p.x -| }
```

## Fixed

```cherimoya
let (p :: arr[2, int]) -> width -> (r :: int) { p[0] -| }
```
