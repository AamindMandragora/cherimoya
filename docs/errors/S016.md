# S016: An uninitialized binding has a type

Topic: 4.8 Uninitialized storage

`<- _` makes a binding without a value, so there's nothing to infer its type from, and the type has to be written.

## Wrong

```cherimoya
let () -> five -> (r :: int) {
    let x :: mut <- _;
    x <- 5;
    x -|
}
```

## Fixed

```cherimoya
let () -> five -> (r :: int) {
    let x :: mut int <- _;
    x <- 5;
    x -|
}
```
