# P024: A wit statement is written 'wit {predicate};'

Topic: 3.10 Verification statements

`wit {p};` is a verification obligation, with its predicate in braces and a `;` after it.

## Wrong

```cherimoya
let (a :: int) -> f -> (r :: int) {
    wit {a > 0;
    a -|
}
```

## Fixed

```cherimoya
let (a :: int) -> f -> (r :: int) {
    wit {a > 0};
    a -|
}
```
