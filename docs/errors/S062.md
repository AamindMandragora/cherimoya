# S062: A call passes as many arguments as its function takes

Topic: 2.2 Calls and methods

A call passes an argument for each input without a default, and no more than there are inputs. A wrong count names the expected count, exactly or as a range when defaults leave one.

## Wrong

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1) -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, 2) -| }
```
