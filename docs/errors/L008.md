# L008: Touching operators need whitespace when one is a flow token, a pipe, a compound, or an extra operator

Topic: 1 Lexical structure

When two operator tokens touch and either one is a flow token, a pipe, a compound, or an extra operator, they have to be separated by whitespace. Maximal munch reads the longest operator it can, so a pair like this could have meant something else, and a space says which reading is meant. `a ** -b` is fine and `a**-b` is not.

## Wrong

```cherimoya
let x :: mut int <- 1;
x <-- 1;
```

## Fixed

```cherimoya
let x :: mut int <- 1;
x <- -1;
```
