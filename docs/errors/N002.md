# N002: Allocators aren't supported yet

Topic: 4.9 Allocators

A handle will be able to name the allocator its memory comes from, `ptr[A, T]` or `arr[A, T]`. The allocator is part of the handle's type, so drop glue always releases memory to the right one.

Allocators aren't built yet, so every handle's memory comes from `Global`, the program-wide default, which is what a bare `ptr[T]` or `arr[T]` already means.

## Wrong

```cherimoya
let (p :: ptr[Global, int]) -> get -> (n :: int) { p[] -| }
```

## Fixed

```cherimoya
let (p :: ptr[int]) -> get -> (n :: int) { p[] -| }
```
