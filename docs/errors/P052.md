# P052: Construction builds from a pack, 'T <- [...]'

Topic: 2.4 Construction, conversion, and annotation

In an expression, an infix `<-` is only ever construction, so it must be followed by `[`: `Point <- [1.0, 2.0]`.

## Wrong

```cherimoya
type Meters <- int;
let m <- Meters <- 5;
```

## Fixed

```cherimoya
type Meters <- int;
let m <- Meters <- [5];
```
