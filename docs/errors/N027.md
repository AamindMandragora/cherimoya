# N027: Construction isn't supported yet

Topic: 2.4 Construction, conversion, and annotation

A construction, `Point <- [3, 4]`, will build a value of a product type or a sum's variant from a pack. It waits for type definitions, which bring the types it builds.

Until then, the pack itself holds the values.

## Wrong

```cherimoya
let () -> origin -> (r :: int) {
    let p <- Point <- [3, 4];
    p[0] -|
}
```

## Fixed

```cherimoya
let () -> origin -> (r :: int) {
    let p <- [3, 4];
    p[0] -|
}
```
