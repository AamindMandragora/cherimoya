# S078: '_' is a place or an initializer

Topic: 3.3 Assignment and expression statements

`_` discards a value as the place of an assignment, `_ <- f();`, and leaves storage uninitialized as an initializer, `<- _`. It has no value of its own, so it can't be used as one.

## Wrong

```cherimoya
let () -> f -> (r :: int) { 1 + _ -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: int) { 1 + 2 -| }
```
