# N012: Variant patterns aren't supported yet

Topic: 3.6 `match`

A variant pattern, `Some[x]`, will match one variant of a sum and bind its payload. Sums come with type definitions.

Until then, a value that might be missing is held in a plain type with a value set aside for none, like `-1` for an index, and a match tests for that value.

## Wrong

```cherimoya
let (n :: int) -> isSet -> (r :: bool) {
    match (n) {
        Some[_] -> { true -| }
        _       -> { false -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> isSet -> (r :: bool) {
    match (n) {
        -1 -> { false -| }
        _  -> { true -| }
    } -|
}
```
