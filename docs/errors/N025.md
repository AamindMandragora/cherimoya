# N025: Calling anything but a function's name isn't supported yet

Topic: 2.2 Calls and methods

A call will take anything that gives a function, like a closure, a function held in an array, or a call that yields one, `f(a)(b)`. That waits for functions as values.

Until then, only a function's name is called, so the function is defined with a name of its own.

## Wrong

```cherimoya
let () -> ten -> (r :: int) {
    ((x :: int) -> (r :: int) { x * 2 -| })(5) -|
}
```

## Fixed

```cherimoya
let (x :: int) -> double -> (r :: int) { x * 2 -| }
let () -> ten -> (r :: int) {
    double(5) -|
}
```
