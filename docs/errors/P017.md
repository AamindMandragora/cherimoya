# P017: Generic arguments are written 'Name[A, B]'

Topic: 5.4 Generics

A generic type's arguments go in brackets after its name, separated by commas, and end with `]`.

## Wrong

```cherimoya
let (o :: Option[int) -> f -> () { }
```

## Fixed

```cherimoya
let (o :: Option[int]) -> f -> () { }
```
