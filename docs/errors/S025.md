# S025: A value has the type its place expects

Topic: 2.4 Construction, conversion, and annotation

Nothing converts without saying so. A value bound with a type, passed to an input, or assigned has to already be of that type, and a literal takes the type it's expected to have when it can. A conversion is written as a call of the type, like `i32(x)`.

## Wrong

```cherimoya
let x :: int <- true;
```

## Fixed

```cherimoya
let x :: bool <- true;
```
