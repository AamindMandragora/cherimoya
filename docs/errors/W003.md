# W003: An arm after ones that match every value never runs

Topic: 3.6 `match`

Arms are tried in order, and the first that matches runs. Once the arms before it cover every value, an arm can never be reached. That's a warning, with a note at the covering arm and a fix that removes the rest.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        _ -> { 0 -| }
        1 -> { 1 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
