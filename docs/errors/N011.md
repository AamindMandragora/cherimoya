# N011: A value out of a loop with a header isn't supported yet

Topic: 3.8 `repeat`

A loop with a header, a for-each or a while, that yields a value will have the type `Option[T]`, which is `None` when the loop finishes without yielding. That waits for sums, which `Option` is.

Until then, a loop that gives a value has no header, since an infinite `repeat { }` only ends by a yield and takes that yield's type, and the condition that would end it becomes an arm that yields the value for none.

## Wrong

```cherimoya
let (n :: int) -> firstBig -> () {
    let i :: mut <- 0;
    let found <- repeat (i < n) {
        match { (i * i > 50) -> { i -| repeat } }
        i +<- 1;
    };
}
```

## Fixed

```cherimoya
let (n :: int) -> firstBig -> () {
    let i :: mut <- 0;
    let found <- repeat {
        match {
            (i >= n)     -> { -1 -| repeat }
            (i * i > 50) -> { i -| repeat }
        }
        i +<- 1;
    };
}
```
