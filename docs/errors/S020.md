# S020: A view or an address is only made in a function

Topic: 4.7 Peek rules

A top-level binding lives as long as the program, while any function can free or move what it would view. A view or an address held there could outlive what it names, so they're only made in functions, where what they name is used.

## Wrong

```cherimoya
let x <- 1;
let v :: peek <- x;
```

## Fixed

```cherimoya
let x <- 1;
let () -> read -> (r :: int) {
    let v :: peek <- x;
    v -|
}
```
