# S085: A handle moved in a loop is assigned again before the iteration ends

Topic: 3.8 `repeat`

A handle declared outside a loop can be moved inside it only if it's assigned again before the iteration ends, since the next iteration, and the code after the loop, expect it to still hold a value.

## Wrong

```cherimoya
let (n :: i64u) -> f -> () { let a <- arr[n, int](0); let i :: mut <- 0; repeat (i < 3) { let b <- a; i +<- 1; } }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> () { let a :: mut <- arr[n, int](0); let i :: mut <- 0; repeat (i < 3) { let b <- a; a <- arr[n, int](0); i +<- 1; } }
```
