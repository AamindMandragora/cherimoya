# N020: Modules aren't supported yet

Topic: 8 Modules and the standard library

One file will be one module, which lists what it exports at its top, `export [area];`, and imports what it uses from others, `import [List] <- list;`.

Until then, a program is one file, so everything it uses is defined in it, and nothing needs exporting.

## Wrong

```cherimoya
export [area];
let (n :: int) -> area -> (r :: int) { n * n -| }
```

## Fixed

```cherimoya
let (n :: int) -> area -> (r :: int) { n * n -| }
```
