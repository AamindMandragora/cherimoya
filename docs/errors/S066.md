# S066: Every input without a default gets an argument

Topic: 2.2 Calls and methods

An input with a default can be left out of a call, but one without a default can't. A call that names its arguments can have enough of them and still leave out an input that needs one, so the error says which.

## Wrong

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(b <- 2) -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, b <- 2) -| }
```
