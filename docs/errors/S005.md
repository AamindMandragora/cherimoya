# S005: Only an array or a pointer can be unscoped

Topic: 4.1 Modes

`unscoped` says a binding owns heap memory that it has to move on before its scope ends. Only arrays and pointers own heap memory, so on anything else `unscoped` means nothing.

## Wrong

```cherimoya
let (n :: unscoped int) -> twice -> (r :: int) { n * 2 -| }
```

## Fixed

```cherimoya
let (n :: int) -> twice -> (r :: int) { n * 2 -| }
```
