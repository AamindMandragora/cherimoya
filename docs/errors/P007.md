# P007: A fold is written '(reducer, seed)[xs]'

Topic: 2.8 Folds

A fold is a reducer and a seed in parentheses, then the sequence in brackets: `(+, 0)[xs]`. A `(` whose contents have a top-level comma and which is followed by `[` is a fold, so it takes exactly a reducer and a seed.

## Wrong

```cherimoya
let xs <- [1, 2, 3];
let total <- (+, 0, 1)[xs];
```

## Fixed

```cherimoya
let xs <- [1, 2, 3];
let total <- (+, 0)[xs];
```
