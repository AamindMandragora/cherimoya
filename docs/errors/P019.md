# P019: A parameter list is written '(name :: Type, name :: Type)'

Topic: 6.1 Signatures

Inputs and outputs are lists of `name :: Type`, separated by commas, in parentheses. Each one starts with its name, which can't be a keyword.

## Wrong

```cherimoya
let (type :: int) -> f -> (r :: int) { 1 -| }
```

## Fixed

```cherimoya
let (kind :: int) -> f -> (r :: int) { 1 -| }
```
