# S086: Nothing a live view points into is freed or moved

Topic: 4.7 Peek rules

While a view is live, from where it's made to its last use, nothing it points into can be freed or moved, so a view never points at memory that's gone. Any number of views can read and write the same place, so only memory going away matters.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { let xs <- arr[n, int](0); let v :: peek <- xs; let ys <- xs; v.len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { let xs <- arr[n, int](0); let v :: peek <- xs; let m <- v.len(); let ys <- xs; m + ys.len() -| }
```
