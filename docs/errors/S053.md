# S053: A conversion is between kinds of values that convert

Topic: 2.4 Construction, conversion, and annotation

A conversion goes between numbers, between characters and integers, or between a `boolf` and a float, a byte, or a bool. Characters never convert to or from floats, and nothing else converts by calling a type.

## Wrong

```cherimoya
let (x :: float) -> f -> (r :: char) { char(x) -| }
```

## Fixed

```cherimoya
let (x :: i8u) -> f -> (r :: char) { char(x) -| }
```
