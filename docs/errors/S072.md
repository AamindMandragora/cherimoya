# S072: Only an array is indexed

Topic: 2.9 Indexing, slicing, dereference, views

`xs[i]` indexes an array, fixed or on the heap. Anything else has no elements to index.

## Wrong

```cherimoya
let (x :: int) -> f -> (r :: int) { x[0] -| }
```

## Fixed

```cherimoya
let (x :: arr[3, int]) -> f -> (r :: int) { x[0] -| }
```
