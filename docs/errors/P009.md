# P009: A map is a pack of pairs, not 'key -> value'

Topic: 2.11 Dictionaries

A dictionary literal is a pack of pairs, converted through the expected type: `[["ada", 36], ["alan", 41]]`. `->` is never a key/value separator.

## Wrong

```cherimoya
let pairs <- [1 -> 2];
```

## Fixed

```cherimoya
let pairs <- [[1, 2]];
```
