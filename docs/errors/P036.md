# P036: An export or import list is written '[Name, Name[field]]'

Topic: 8 Modules and the standard library

An export or import list is a pack of names: functions, types, and operators. Exporting a type doesn't export its fields, which are listed in brackets after it, as in `Result[dist, prev]`.

## Wrong

```cherimoya
export [f, 1];
let () -> f -> () { }
```

## Fixed

```cherimoya
export [f];
let () -> f -> () { }
```
