# S030: A function's yields have its output's type

Topic: 3.4 Yields (`-|`)

A function's type is declared in its signature, so every yield to it is checked against its output, with a note where the output is declared.

## Wrong

```cherimoya
let () -> one -> (r :: int) { true -| }
```

## Fixed

```cherimoya
let () -> one -> (r :: int) { 1 -| }
```
