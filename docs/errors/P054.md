# P054: '|>' and '<|' need parentheses to mix

Topic: 2.3 Pipes

`|>` is left-associative and `<|` is right-associative, so mixing them in one expression without parentheses is an error. Parentheses, brackets, and arguments start fresh, so `f <| (x |> g)` is fine.

## Wrong

```cherimoya
let (a :: int) -> inc -> (r :: int) { a + 1 -| }
let (a :: int) -> double -> (r :: int) { a * 2 -| }
let x <- double <| 1 |> inc;
```

## Fixed

```cherimoya
let (a :: int) -> inc -> (r :: int) { a + 1 -| }
let (a :: int) -> double -> (r :: int) { a * 2 -| }
let x <- double <| (1 |> inc);
```
