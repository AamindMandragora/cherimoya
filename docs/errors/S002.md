# S002: A top-level binding can't be moved

Topic: 4.5 Ownership and moves

A top-level binding is a global, so any function can use it at any time. Moving it out would leave it holding nothing while some other function still expects it to hold a value, so a top-level binding that owns a handle can only be used in place.

## Wrong

```cherimoya
let size :: mut i64u <- 3;
let table <- arr[size, int](0);
let () -> grab -> (r :: arr[int]) { table -| }
```

## Fixed

```cherimoya
let size :: mut i64u <- 3;
let table <- arr[size, int](0);
let () -> count -> (r :: i64u) { table.len() -| }
```
