# L003: An escape has to be one of the escapes a literal holds

Topic: 1 Lexical structure

After a `\` in a string or char literal comes one of `\n`, `\t`, `\r`, `\0`, `\\`, `\'`, `\"`, `\xHH` with two hex digits, or `\u{H...}` with 1 to 6 hex digits in braces. Anything else after a `\` is an error that lists the escapes.

A backslash that should be in the text is written `\\`.

## Wrong

```cherimoya
let path <- "C:\path";
```

## Fixed

```cherimoya
let path <- "C:\\path";
```
