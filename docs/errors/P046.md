# P046: Conditional flow is a match, since there is no 'if'

Topic: 3.5 Conditionals

There is no `if`. Every conditional is a `match`, with a subject or subjectless, and a one-arm subjectless match is the guard form. `if` lexes as a name, and `if (` gets this error pointing at `match`.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: int) {
    if (n > 0) { 1 -| }
    0 -|
}
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match { (n > 0) -> { 1 -| f } }
    0 -|
}
```
