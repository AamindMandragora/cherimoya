# P016: An exclusivity marker goes only on a range's endpoints

Topic: 2.6 Ranges

An exclusivity marker, like the `<` in `[0, ..., <n]`, says a range stays above or below a bound. Only a range's first and last values are bounds, so a marker anywhere else, or in a pack that isn't a range, is an error.

## Wrong

```cherimoya
let xs <- [1, <2, 3];
```

## Fixed

```cherimoya
let xs <- [1, 2, 3];
```
