# S035: A value is used or discarded

Topic: 3.3 Assignment and expression statements

A value can't be dropped on the floor. An expression statement whose type isn't `void` or `never` has to be discarded explicitly with `_ <-`, so a value that could be an error is never ignored.

## Wrong

```cherimoya
let () -> one -> (r :: int) { 1 -| }
let () -> run -> () { one(); }
```

## Fixed

```cherimoya
let () -> one -> (r :: int) { 1 -| }
let () -> run -> () { _ <- one(); }
```
