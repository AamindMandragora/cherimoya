# N007: More than one output isn't supported yet

Topic: 6.1 Signatures

A function will be able to have several outputs, yielded together as a pack, `[q, r] -|`, and taken apart by the caller with destructuring.

That waits for tuples, so a function has one output for now, and a function that would give two is written as two functions.

## Wrong

```cherimoya
let (a :: int, b :: int) -> divmod -> (q :: int, r :: int) { [a / b, a % b] -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> quotient -> (q :: int) { a / b -| }
let (a :: int, b :: int) -> remainder -> (r :: int) { a % b -| }
```
