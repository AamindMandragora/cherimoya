# P039: A handle is written 'arr[T]', 'arr[size, T]', or 'ptr[T]', with a type for what it holds

Topic: 4.3 Arrays and handles

Handles take what they hold in brackets, like any generic, after a size or an allocator when there is one: `arr[3, int]` or `arr[int]`. What a handle holds is always a type, so a value in its place is an error.

## Wrong

```cherimoya
let xs :: arr[3] <- [1, 2, 3];
```

## Fixed

```cherimoya
let xs :: arr[3, int] <- [1, 2, 3];
```
