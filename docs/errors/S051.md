# S051: A conversion takes one value

Topic: 2.4 Construction, conversion, and annotation

A conversion turns one value into another type, so it takes exactly one value.

## Wrong

```cherimoya
let (x :: int) -> f -> (r :: i32) { i32(x, 1) -| }
```

## Fixed

```cherimoya
let (x :: int) -> f -> (r :: i32) { i32(x) -| }
```
