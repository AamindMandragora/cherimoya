# S067: A method without its object is piped into

Topic: 2.3 Pipes

A method is called on its object. Written with its dot and no object, `.len`, it gets its object from a pipe, `xs |> .len`, and anywhere else it has none.

## Wrong

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { .len -| }
```

## Fixed

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { xs |> .len -| }
```
