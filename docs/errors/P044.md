# P044: A block is written '{ statements }'

Topic: 3.1 General

A body, an arm, and a loop each hold a block, a list of statements in braces, closed with `}`.

## Wrong

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let (a :: int) -> f -> (r :: int) { a -|
```

## Fixed

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let (a :: int) -> f -> (r :: int) { a -| }
```
