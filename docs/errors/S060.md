# S060: An array's length goes in brackets

Topic: 4.3 Arrays and handles

An array's length goes in brackets, where a fixed array's size does, `arr[n, T](fill)`, and the size alone decides what's made: a fixed array when it's known while compiling, and an array on the heap when it isn't. The value in parentheses is the fill. The error moves the length into the brackets, with a fix.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[int](n).len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, int](0).len() -| }
```
