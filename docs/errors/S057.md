# S057: An array made without a fill needs elements with a default

Topic: 4.3 Arrays and handles

`arr[n, T]()` fills its elements with `T`'s default. A pointer is never null, so it has no default, and neither does anything holding one. Those arrays need a fill, which each element gets a deep copy of.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, ptr[int]]().len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, ptr[int]](ptr[int](0)).len() -| }
```
