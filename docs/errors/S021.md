# S021: An address is of a place

Topic: 2.9 Indexing, slicing, dereference, views

`addr x` is the address of a place, which says whether two places are the same one. A value that isn't a place, like `x + 1`, has no place to name, so it's bound first and the binding's address taken.

## Wrong

```cherimoya
let (x :: int) -> same -> (r :: bool) { addr x = addr (x + 1) -| }
```

## Fixed

```cherimoya
let (x :: int) -> same -> (r :: bool) {
    let y <- x + 1;
    addr x = addr y -|
}
```
