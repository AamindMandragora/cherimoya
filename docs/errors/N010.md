# N010: Destructuring isn't supported yet

Topic: 3.2 Bindings

A binding whose pattern is a pack, `let [q, r] <- divmod(17, 5);`, will take the value apart, binding each element to its own name.

Until then, the whole value is bound to one name, and each element is read from it by its index.

## Wrong

```cherimoya
let (n :: int) -> split -> () {
    let [q, r] <- [n / 5, n % 5];
}
```

## Fixed

```cherimoya
let (n :: int) -> split -> () {
    let qr <- [n / 5, n % 5];
    let q <- qr[0];
    let r <- qr[1];
}
```
