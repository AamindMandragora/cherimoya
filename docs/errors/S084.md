# S084: An unscoped owner is moved before its scope ends

Topic: 4.1 Modes

`unscoped` owns heap memory that must be discharged before its scope ends: yielded, moved into something that outlives the scope, or passed to an `unscoped` input. Its scope never frees it, so letting it go any other way would leak it.

## Wrong

```cherimoya
let (xs :: unscoped arr[int]) -> lose -> () { }
```

## Fixed

```cherimoya
let (xs :: unscoped arr[int]) -> keep -> (r :: arr[int]) { xs -| }
```
