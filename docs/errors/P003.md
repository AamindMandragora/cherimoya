# P003: A bare operator in parentheses is only a fold's reducer

Topic: 2.8 Folds

A fold takes a bare operator as its reducer, `(+, 0)[xs]`. An operator alone in parentheses, `(+)`, is reserved, so it's an error on its own.

## Wrong

```cherimoya
let xs <- [1, 2, 3];
let total <- (+);
```

## Fixed

```cherimoya
let xs <- [1, 2, 3];
let total <- (+, 0)[xs];
```
