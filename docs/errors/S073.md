# S073: An array takes one index

Topic: 2.9 Indexing, slicing, dereference, views

An array is indexed by one unsigned integer. A nested array takes one index per level, `m[i][j]`.

## Wrong

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[0, 1] -| }
```

## Fixed

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[0] -| }
```
