# S065: An input gets one argument

Topic: 2.2 Calls and methods

Each input gets one argument, so an argument naming an input that already has one is an error, with a note at the first.

## Wrong

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, a <- 2) -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, b <- 2) -| }
```
