# P010: A comprehension's clauses are joined with '&&'

Topic: 2.7 Comprehensions

Clauses are joined with `&&`, and `||` between them is rejected. Clauses are parsed just above `&&`'s level, so a `||` inside a filter clause needs parentheses.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [x : x > 0 && x < 5 || x > 9] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        [x : x > 0 && (x < 5 || x > 9)] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
