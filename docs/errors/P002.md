# P002: An empty pack is written '[]', not '()'

Topic: 2.10 Packs, tuples, and records

Packs are written in brackets, and that includes the empty one. `()` is void in a signature, but in an expression it's an error, with a fix that turns the parentheses into brackets. An empty pack takes its type from where it goes.

## Wrong

```cherimoya
let empty <- ();
```

## Fixed

```cherimoya
let empty :: arr[0, int] <- [];
```
