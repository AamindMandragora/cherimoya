# S022: An address is never mut

Topic: 2.9 Indexing, slicing, dereference, views

An address is checked like a view: it names one place for as long as it's used, so two equal addresses always name the same memory. A `mut` binding could be pointed somewhere else partway through, so a binding holding an address is never `mut`.

## Wrong

```cherimoya
let (x :: int) -> same -> (r :: bool) {
    let a :: mut addr[int] <- addr x;
    a = addr x -|
}
```

## Fixed

```cherimoya
let (x :: int) -> same -> (r :: bool) {
    let a :: addr[int] <- addr x;
    a = addr x -|
}
```
