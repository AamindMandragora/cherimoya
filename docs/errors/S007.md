# S007: A condition has to be a bool

Topic: 3.6 `match`

A guard, a loop's condition, an assertion, a refinement, and a `wit` obligation decide one way or the other, so each has to be a `bool`. Nothing converts to a `bool` without saying so: a number is compared to something.

A `boolf` is never a condition either. Turning 0.7 into a yes or a no is a choice, so the program writes the cutoff it means, like `x > 0.5`.

## Wrong

```cherimoya
let (n :: int) -> check -> () { assert (n); }
```

## Fixed

```cherimoya
let (n :: int) -> check -> () { assert (n > 0); }
```
