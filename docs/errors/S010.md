# S010: `@test` goes on a function

Topic: 12 Tests

A test is a function marked `@test`, which `cheri test` calls. Anything else, like a binding, can't be run, so `@test` on it is an error.

## Wrong

```cherimoya toya
@test
let limit <- 3;
@test
let () -> small -> () { assert (limit < 5); }
```

## Fixed

```cherimoya toya
let limit <- 3;
@test
let () -> small -> () { assert (limit < 5); }
```
