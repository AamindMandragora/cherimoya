# S075: An index known when the program compiles is in range

Topic: 2.9 Indexing, slicing, dereference, views

An index into a fixed array is checked at run time, unless it's known while compiling, and then it's checked right away, so a mistake shows up before the program runs.

## Wrong

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[5] -| }
```

## Fixed

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[2] -| }
```
