# S029: A yield's target is a function or scope around it

Topic: 3.4 Yields (`-|`)

`-| name` yields to the function or scope named `name`, found by walking outward from the yield. The search stops at the nearest function, so a yield can't reach into one around it, and a name that isn't found there is an error.

## Wrong

```cherimoya
let () -> run -> () { -| outer }
```

## Fixed

```cherimoya
let () -> run -> () { -| run }
```
