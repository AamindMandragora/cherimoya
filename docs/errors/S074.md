# S074: An index is an integer

Topic: 2.9 Indexing, slicing, dereference, views

An index counts elements from 0, so it has to be an unsigned integer. A literal index is an `i64u`.

## Wrong

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[1.0] -| }
```

## Fixed

```cherimoya
let (xs :: arr[3, int]) -> f -> (r :: int) { xs[1] -| }
```
