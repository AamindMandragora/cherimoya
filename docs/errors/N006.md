# N006: Record types aren't supported yet

Topic: 2.10 Packs, tuples, and records

A record type, `[x :: f64, y :: f64]`, will hold named fields, typed structurally, which are reached with `.x` or by position with `[0]`.

Records aren't built yet, so the fields are passed as values of their own, or as an array when they share a type.

## Wrong

```cherimoya
let (p :: [x :: f64, y :: f64]) -> sum -> (r :: f64) { p.x + p.y -| }
```

## Fixed

```cherimoya
let (x :: f64, y :: f64) -> sum -> (r :: f64) { x + y -| }
```
