# S014: Every path through a scope that yields a value has to yield one

Topic: 3.4 Yields (`-|`)

A function's type is declared, and every other scope's type comes from what's yielded to it. When some path yields a value and another can fall off the end, the scope would have no value on that path, so every path has to end with a yield. The same goes for a function that yields something other than `void`.

## Wrong

```cherimoya
let (n :: int) -> sign -> (r :: int) {
    match { (n < 0) -> { -1 -| sign } }
}
```

## Fixed

```cherimoya
let (n :: int) -> sign -> (r :: int) {
    match { (n < 0) -> { -1 -| sign } }
    1 -|
}
```
