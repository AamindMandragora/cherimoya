# P004: A tuple is a pack in brackets, not a list in parentheses

Topic: 2.10 Packs, tuples, and records

A tuple is a pack, `[a, b]`, with the same layout as a fixed array when its elements share a type. Parentheses only group, so `(a, b)` in an expression is an error, with a fix that turns the parentheses into brackets.

## Wrong

```cherimoya
let x <- (1, 2);
```

## Fixed

```cherimoya
let x <- [1, 2];
```
