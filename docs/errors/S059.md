# S059: An uninitialized array's elements are mutable

Topic: 4.8 Uninitialized storage

Elements left uninitialized with `_` only get their values by being written, so they have to be declared `mut`.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, int](_).len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, mut int](_).len() -| }
```
