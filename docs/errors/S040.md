# S040: Only a binding declared mut can be assigned

Topic: 3.3 Assignment and expression statements

Bindings are immutable unless they're declared `mut`, so a binding that's never meant to change can't be changed by mistake, and reading the declaration says whether it ever does.

The error says how to declare it, with a fix.

## Wrong

```cherimoya
let () -> f -> (r :: int) { let x <- 1; x <- 2; x -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: int) { let x :: mut <- 1; x <- 2; x -| }
```
