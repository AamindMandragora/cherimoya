# S011: A `@test` takes `traps` and `timeout`, named, each once

Topic: 12 Tests

`@test` takes two optional arguments: `traps`, text the trap's message must hold for a test that passes by trapping, and `timeout`, the seconds after which the test fails. Each is named and given at most once. An unnamed argument, another name, or the same name twice is an error.

## Wrong

```cherimoya toya
@test(5)
let () -> quick -> () { assert (1 < 2); }
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```

## Fixed

```cherimoya toya
@test(timeout <- 5)
let () -> quick -> () { assert (1 < 2); }
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```
