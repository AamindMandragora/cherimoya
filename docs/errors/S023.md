# S023: A view writes only what its place can write

Topic: 4.7 Peek rules

A view reads and writes as the place it views, so what it can write has to be writable where it comes from. Otherwise a `peek mut` would be a way around a binding declared immutable.

## Wrong

```cherimoya
let () -> bump -> (r :: int) {
    let x <- 1;
    let v :: peek mut <- x;
    v <- 2;
    x -|
}
```

## Fixed

```cherimoya
let () -> bump -> (r :: int) {
    let x :: mut <- 1;
    let v :: peek mut <- x;
    v <- 2;
    x -|
}
```
