# S038: Only mutable elements can be assigned

Topic: 4.2 Qualifier positions

Where `mut` sits decides what a binding can write: `mut arr[T]` replaces the whole array, and `arr[mut T]` writes its elements. Writing an element needs `mut` on the elements, at the level being written, so `m[i][j]` in `arr[2, arr[3, mut int]]`.

## Wrong

```cherimoya
let (xs :: arr[int]) -> clear -> () { xs[0] <- 0; }
```

## Fixed

```cherimoya
let (xs :: arr[mut int]) -> clear -> () { xs[0] <- 0; }
```
