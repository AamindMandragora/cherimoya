# P030: A loop is written 'repeat (binder) <- source wit {invariant} { body }'

Topic: 3.8 `repeat`

A loop is `repeat`, an optional header in parentheses, `(binder) <- source` for for-each or `(cond)` for while, an optional invariant in braces after `wit`, and its body.

## Wrong

```cherimoya
let (n :: mut int) -> f -> (r :: int) {
    repeat (n > 0: { n -<- 1; }
    n -|
}
```

## Fixed

```cherimoya
let (n :: mut int) -> f -> (r :: int) {
    repeat (n > 0) { n -<- 1; }
    n -|
}
```
