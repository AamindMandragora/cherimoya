# N026: old isn't supported yet

Topic: 5.2 Refinements

Inside an output's refinement, `old p` will be the input `p` as it was when the function started, so a postcondition can say how the function changed it, `{nodeCount(g) = nodeCount(old g)}`. That waits for contracts.

Until then, the value is bound to a name of its own before it changes.

## Wrong

```cherimoya
let (n :: mut int) -> bump -> (r :: int) {
    n +<- 1;
    n - old n -|
}
```

## Fixed

```cherimoya
let (n :: mut int) -> bump -> (r :: int) {
    let start <- n;
    n +<- 1;
    n - start -|
}
```
