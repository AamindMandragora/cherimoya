# N018: Protocol assertions aren't supported yet

Topic: 5.3 Protocols

`wit {T :: P};` will assert, where it's written, that the type `T` follows the protocol `P`, which is that functions matching every signature in `P` are visible. Protocols aren't built yet.

Until then, there are no protocols to assert, and the built-in operations a type has, like comparing integers, are used directly.

## Wrong

```cherimoya
wit {int :: Ord};
let (a :: int, b :: int) -> less -> (r :: bool) { a < b -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> less -> (r :: bool) { a < b -| }
```
