# P027: A match is written 'match (subject) { arms }'

Topic: 3.6 `match`

A match is `match`, its subject in parentheses if it has one, and its arms in braces, closed with `}`.

## Wrong

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let x <- 1;
match (x) {
    1 -> { }
    _ -> { }
```

## Fixed

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let x <- 1;
match (x) {
    1 -> { }
    _ -> { }
}
```
