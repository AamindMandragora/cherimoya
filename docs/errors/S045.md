# S045: A char literal has to be ASCII

Topic: 5.7 Characters

A `char` holds one ASCII character, so it's always a whole character: a byte above 7F is part of a longer UTF-8 sequence. A character past ASCII is a `rune`.

## Wrong

```cherimoya
let () -> f -> (r :: char) { 'é' -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: rune) { 'é' -| }
```
