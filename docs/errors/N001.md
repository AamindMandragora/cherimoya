# N001: Types that aren't built in aren't supported yet

Topic: 5.1 Definitions

Only the built-in types can be named today: the integers, the floats, `bool`, `boolf`, `char`, `rune`, and arrays, pointers and addresses of them. Every other type, like a program's own `Point` or `Option[int]` and `List[int]`, will come from type definitions, the prelude and the standard library.

Until then, a value is written as the built-in types it's made of, like a point as a pack of two floats.

## Wrong

```cherimoya
let (p :: Point) -> first -> (x :: f64) { p[0] -| }
```

## Fixed

```cherimoya
let (p :: arr[2, f64]) -> first -> (x :: f64) { p[0] -| }
```
