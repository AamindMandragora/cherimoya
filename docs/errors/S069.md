# S069: A method is one its object's type has

Topic: 2.2 Calls and methods

Methods are what protocols give the types that implement them, so an object only has the methods of the protocols its type implements. Every array has `len`, from `Sized`.

## Wrong

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { xs.size() -| }
```

## Fixed

```cherimoya
let (xs :: arr[int]) -> f -> (r :: i64u) { xs.len() -| }
```
