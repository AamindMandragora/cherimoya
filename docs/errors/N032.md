# N032: Closures aren't supported yet

Topic: 2.12 Closures

A closure, `(x :: int) -> (r :: int) { x * x -| }`, will be a function without a name, written where it's used, which views the locals it mentions and can own the ones it captures.

Until then, the function is defined with a name, and whatever it would capture is passed to it as an input.

## Wrong

```cherimoya
let () -> nine -> (r :: int) {
    let square <- (x :: int) -> (r :: int) { x * x -| };
    square(3) -|
}
```

## Fixed

```cherimoya
let (x :: int) -> square -> (r :: int) { x * x -| }
let () -> nine -> (r :: int) {
    square(3) -|
}
```
