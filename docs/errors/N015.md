# N015: Set-builder patterns aren't supported yet

Topic: 3.6 `match`

A set-builder pattern, `[x : x % 2 = 0]`, will match every value its predicate holds for, binding the value to the name before `:`.

Until then, a match without a subject tests the predicate as a guard on the value itself.

## Wrong

```cherimoya
let (n :: int) -> parity -> (r :: int) {
    match (n) {
        [x : x % 2 = 0] -> { 0 -| }
        _               -> { 1 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> parity -> (r :: int) {
    match {
        (n % 2 = 0) -> { 0 -| }
        _           -> { 1 -| }
    } -|
}
```
