# L004: A \u{...} escape has to name a Unicode scalar value

Topic: 1 Lexical structure

`\u{...}` names any Unicode scalar value, which is every code point from 0 to 10FFFF except the surrogates, D800 to DFFF. A surrogate is half of a pair UTF-16 uses, not a character on its own, and nothing past 10FFFF is a code point, so neither can be in a literal.

## Wrong

```cherimoya
let s <- "\u{D800}";
```

## Fixed

```cherimoya
let s <- "\u{1F600}";
```
