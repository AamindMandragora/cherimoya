# S015: A view is of a place

Topic: 4.7 Peek rules

A view, `peek`, holds the address of a place it reads and writes as. A value that isn't a place, like the result of `1 + 2`, is gone once its statement ends, so a view of it would point at nothing. The value is bound first, and the binding viewed.

## Wrong

```cherimoya
let () -> three -> (r :: int) {
    let v :: peek <- 1 + 2;
    v -|
}
```

## Fixed

```cherimoya
let () -> three -> (r :: int) {
    let x <- 1 + 2;
    let v :: peek <- x;
    v -|
}
```
