# N034: A test with inputs or outputs isn't built yet

Topic: 12 Tests

A test with no inputs runs once. A test with inputs will be fuzzed against its contracts, with Z3 counterexamples as cases, which isn't built yet, so for now a test takes and yields nothing, and makes its own values.

## Wrong

```cherimoya toya
@test
let (n :: int) -> positive -> () { assert (n * n >= 0); }
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```

## Fixed

```cherimoya toya
@test
let () -> positive -> () {
    let n <- 3;
    assert (n * n >= 0);
}
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```
