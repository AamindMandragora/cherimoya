# S071: Only a pointer is dereferenced

Topic: 2.9 Indexing, slicing, dereference, views

`p[]` reads the value a pointer points at. Anything else has nothing to point at.

## Wrong

```cherimoya
let (x :: int) -> f -> (r :: int) { x[] -| }
```

## Fixed

```cherimoya
let (x :: ptr[int]) -> f -> (r :: int) { x[] -| }
```
