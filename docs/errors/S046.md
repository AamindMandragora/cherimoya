# S046: A string of chars has to be ASCII

Topic: 5.8 Strings

A string literal is the kind of string its context wants. A string of chars holds only ASCII, a byte each, so a literal with a character past ASCII can't be one. It can be UTF-8 bytes, `arr[i8u]`, or runes, `arr[rune]`.

## Wrong

```cherimoya
let () -> f -> (r :: arr[6, char]) { "héllo" -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: arr[6, i8u]) { "héllo" -| }
```
