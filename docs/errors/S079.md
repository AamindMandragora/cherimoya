# S079: A program has a start function

Topic: 6.4 Programs and the top level

A program begins at its entry, `start`, at the top of the file, and its result is the exit code. It's called `start` so it never shares a name with the C `main` the runtime defines. The error adds one, with a fix.

## Wrong

```cherimoya whole
let () -> f -> () { }
```

## Fixed

```cherimoya
let () -> f -> () { }
let () -> start -> (code :: int) { 0 -| }
```
