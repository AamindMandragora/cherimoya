# P035: A protocol is written 'type Name <- [let ..., let ...];'

Topic: 5.3 Protocols

A protocol is a pack of signatures, separated by commas, recognized by the leading `let`, and closed with `]`.

## Wrong

```cherimoya
type Shout[T] <- [let (a :: T) -> shout -> (r :: T);
```

## Fixed

```cherimoya
type Shout[T] <- [let (a :: T) -> shout -> (r :: T)];
```
