# S058: An uninitialized array's elements own nothing

Topic: 4.8 Uninitialized storage

`arr[n, mut T](_)` leaves its elements uninitialized. Until Z3 can prove the elements are written before they're dropped, only elements that own nothing can start out uninitialized, since dropping one that was never written would free garbage.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, mut ptr[int]](_).len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, mut int](_).len() -| }
```
