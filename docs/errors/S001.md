# S001: An index has to be unsigned

Topic: 2.9 Indexing, slicing, dereference, views

An array is indexed from 0, so an index below 0 can never be in range. Indexing only takes an unsigned integer, so a negative index can't be written at all, and only the end of the array has to be checked.

A signed index has to be converted first. `i64u(i)` converts it, and traps if `i` is negative, which is where the mistake is.

## Wrong

```cherimoya
let (xs :: arr[3, int], i :: int) -> pick -> (x :: int) { xs[i] -| }
```

## Fixed

```cherimoya
let (xs :: arr[3, int], i :: int) -> pick -> (x :: int) { xs[i64u(i)] -| }
```
