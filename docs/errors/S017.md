# S017: An uninitialized binding owns nothing

Topic: 4.8 Uninitialized storage

Freeing a handle that was never written would free memory it never had. Until Z3 can prove a binding is written before it's freed, a binding that owns something, like an array on the heap, can't start out uninitialized.

## Wrong

```cherimoya
let () -> count -> (r :: i64u) {
    let xs :: mut arr[int] <- _;
    xs <- arr[int]([1, 2]);
    xs.len() -|
}
```

## Fixed

```cherimoya
let () -> count -> (r :: i64u) {
    let xs :: mut arr[int] <- arr[int]([1, 2]);
    xs.len() -|
}
```
