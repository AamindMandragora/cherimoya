# S006: An address names what a pointer points at

Topic: 2.9 Indexing, slicing, dereference, views

An address, `addr[T]`, says whether two places are the same one. A pointer's address is what it points at, through every pointer, so an address never names a pointer itself, and `addr[ptr[T]]` is written `addr[T]`.

## Wrong

```cherimoya
let (a :: addr[ptr[int]], b :: addr[ptr[int]]) -> same -> (r :: bool) { a = b -| }
```

## Fixed

```cherimoya
let (a :: addr[int], b :: addr[int]) -> same -> (r :: bool) { a = b -| }
```
