# N024: Slicing isn't supported yet

Topic: 2.9 Indexing, slicing, dereference, views

A slice, `xs[a, ..., <b]`, will be a `peek` view of part of an array, checked against its bounds once when it's made.

Until then, the elements are indexed directly, or the whole array is passed along with the bounds of the part.

## Wrong

```cherimoya
let (xs :: arr[4, int]) -> front -> (r :: int) {
    let ys <- xs[0, ..., <2];
    ys[0] + ys[1] -|
}
```

## Fixed

```cherimoya
let (xs :: arr[4, int]) -> front -> (r :: int) {
    xs[0] + xs[1] -|
}
```
