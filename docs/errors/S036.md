# S036: A name is declared before it's used

Topic: 6.3 Order and nesting

Statements are checked in order, so a `let` is only visible after it. Functions and globals are the exception, since every signature is declared before anything else is checked.

## Wrong

```cherimoya
let () -> one -> (r :: int) { y -| }
```

## Fixed

```cherimoya
let () -> one -> (r :: int) {
    let y <- 1;
    y -|
}
```
