# N030: Folds aren't supported yet

Topic: 2.8 Folds

A fold, `(+, 0)[xs]`, will combine every element of a sequence with its reducer, an operator, a function, or a closure, starting from its seed. An operator alone in parentheses is only ever a fold's reducer, so it reports this too.

Until then, a loop adds each element into a binding.

## Wrong

```cherimoya
let (xs :: arr[int]) -> total -> (r :: int) {
    (+, 0)[xs] -|
}
```

## Fixed

```cherimoya
let (xs :: arr[int]) -> total -> (r :: int) {
    let s :: mut <- 0;
    let i :: mut i64u <- 0;
    repeat (i < xs.len()) {
        s +<- xs[i];
        i +<- 1;
    }
    s -|
}
```
