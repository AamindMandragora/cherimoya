# N016: For-each loops aren't supported yet

Topic: 3.8 `repeat`

A for-each loop, `repeat (x) <- xs { }`, will run its body once for each element of a range, an array, or anything `Iterable`, binding the element to the name in its header.

Until then, a while loop counts an index up to the array's length, and reads each element by it.

## Wrong

```cherimoya
let (xs :: arr[int]) -> total -> (r :: int) {
    let s :: mut <- 0;
    repeat (x) <- xs { s +<- x; }
    s -|
}
```

## Fixed

```cherimoya
let (xs :: arr[int]) -> total -> (r :: int) {
    let s :: mut <- 0;
    let i :: mut i64u <- 0;
    repeat (i < xs.len()) {
        s +<- xs[i];
        i +<- 1;
    }
    s -|
}
```
