# N003: wit values aren't supported yet

Topic: 3.2 Bindings

A `wit` binding, `let n0 :: wit <- nodeCount(g);`, will be a value only the verifier sees. It may appear only in `wit`, `assert`, and refinements, never flows into a value the program runs with, and costs nothing at run time. It waits for contracts, which bring the verifier.

Until then, an ordinary binding holds the value, and `assert` checks it at run time.

## Wrong

```cherimoya
let (n :: int) -> same -> (r :: int) {
    let n0 :: wit <- n;
    assert (n0 = n);
    n -|
}
```

## Fixed

```cherimoya
let (n :: int) -> same -> (r :: int) {
    let n0 <- n;
    assert (n0 = n);
    n -|
}
```
