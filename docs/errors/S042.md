# S042: An integer literal has to be exact in the float it stands for

Topic: 5.6 Floats

An integer literal can stand for a float, so `x * 2` works on a float `x`, but only when the float holds it exactly. A literal that would round is rejected, so a whole number never quietly changes its value.

Write it as a float literal to accept the rounding, or use a wider type that holds it.

## Wrong

```cherimoya
let () -> f -> (r :: f16) { 2049 -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: f32) { 2049 -| }
```
