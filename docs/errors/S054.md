# S054: An array's length is an integer

Topic: 4.3 Arrays and handles

An array's length goes in brackets, `arr[n, T](fill)`, and it counts elements, so it has to be an integer.

## Wrong

```cherimoya
let (n :: float) -> f -> (r :: i64u) { arr[n, int](0).len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { arr[n, int](0).len() -| }
```
