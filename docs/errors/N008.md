# N008: Operator overloading isn't supported yet

Topic: 5.3 Protocols

A function whose name is an operator, `let (a :: Vec2, b :: Vec2) -> + -> (r :: Vec2)`, will overload it, so the operator works on the types the function takes. Overloading comes with protocols, since each operator is one, like `Add` for `+`.

Until then, the operation is a function with a name of its own, called like any other.

## Wrong

```cherimoya
let (a :: arr[2, int], b :: arr[2, int]) -> + -> (r :: arr[2, int]) {
    [a[0] + b[0], a[1] + b[1]] -|
}
```

## Fixed

```cherimoya
let (a :: arr[2, int], b :: arr[2, int]) -> add -> (r :: arr[2, int]) {
    [a[0] + b[0], a[1] + b[1]] -|
}
```
