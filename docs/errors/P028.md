# P028: A match arm is written 'pattern -> { body }'

Topic: 3.6 `match`

Arms are `pattern -> { body }`, with nothing between them. In a subjectless match, a guard's condition is in parentheses, `(condition) -> { body }`.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (n) {
        1 <- { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match (n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
