# S083: A moved binding holds nothing until it's assigned again

Topic: 4.5 Ownership and moves

An owned handle has one owner, so binding it, assigning it, yielding it, or putting it in a pack moves it, and the place it came from holds nothing. Using it before assigning it again would read memory its new owner may already have freed.

## Wrong

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { let a <- arr[n, int](0); let b <- a; a.len() -| }
```

## Fixed

```cherimoya
let (n :: i64u) -> f -> (r :: i64u) { let a <- arr[n, int](0); let b <- a; b.len() -| }
```
