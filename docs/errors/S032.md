# S032: A pattern has the subject's type

Topic: 3.6 `match`

A literal pattern is compared with the subject, so it has to be of the subject's type, where a literal adapts to the subject's type when it can.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        true -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
