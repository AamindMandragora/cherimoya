# L002: A string or char literal has to be closed

Topic: 1 Lexical structure

A string literal runs from `"` to the next `"`, and a char literal from `'` to the next `'`. A literal that reaches the end of the file without its closing quote is reported at its opening quote, since that is where the literal that never ends starts.

## Wrong

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let s <- "abc
```

## Fixed

```cherimoya
let () -> start -> (code :: int) { 0 -| }
let s <- "abc";
```
