# S028: A yield is inside a function or scope

Topic: 3.4 Yields (`-|`)

`-|` yields to a scope around it, a block, a match arm, a loop, or a function. At the top of a file there's no scope to yield to.

## Wrong

```cherimoya
let x <- 1;
x -|
```

## Fixed

```cherimoya
let () -> one -> (r :: int) {
    let x <- 1;
    x -|
}
```
