# N014: Range patterns aren't supported yet

Topic: 3.6 `match`

A range pattern, `[0, ..., 100]`, will match every value in a range, and exhaustiveness will check the ranges against the subject's domain by interval arithmetic.

Until then, a match without a subject tests each range as a guard, in order, with `_` for the rest.

## Wrong

```cherimoya
let (n :: int) -> clamp -> (r :: int) {
    match (n) {
        [..., <0]     -> { 0 -| }
        [0, ..., 100] -> { n -| }
        _             -> { 100 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> clamp -> (r :: int) {
    match {
        (n < 0)    -> { 0 -| }
        (n <= 100) -> { n -| }
        _          -> { 100 -| }
    } -|
}
```
