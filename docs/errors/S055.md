# S055: A run-time array length is unsigned

Topic: 4.3 Arrays and handles

A length known only at run time makes an array on the heap, and that length is any unsigned integer, like an index, since a length below zero means nothing. A signed length has to be converted first, which traps if it's negative.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: i64u) { arr[n, int](0).len() -| }
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: i64u) { arr[i64u(n), int](0).len() -| }
```
