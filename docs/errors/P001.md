# P001: An argument list is written 'f(a, b)'

Topic: 2.2 Calls and methods

A call's arguments, and an attribute's, go in parentheses after it, separated by commas, and end with `)`.

## Wrong

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let x <- add(1, 2;
```

## Fixed

```cherimoya
let (a :: int, b :: int) -> add -> (r :: int) { a + b -| }
let x <- add(1, 2);
```
