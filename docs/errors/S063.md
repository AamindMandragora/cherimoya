# S063: A named argument names an input

Topic: 2.2 Calls and methods

An argument is named with `<-`, and it goes to the input it names. A name that isn't an input goes nowhere, so the error lists the inputs there are.

## Wrong

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, c <- 2) -| }
```

## Fixed

```cherimoya
let (a :: int, b :: int <- 0) -> add -> (r :: int) { a + b -| }
let () -> f -> (r :: int) { add(1, b <- 2) -| }
```
