# P005: An annotation is written '(value :: Type)'

Topic: 2.4 Construction, conversion, and annotation

An annotation checks a value against a type, and is written in parentheses, `(value :: T)`, closed with `)` after the type.

## Wrong

```cherimoya
let x <- (5 :: i8;
```

## Fixed

```cherimoya
let x <- (5 :: i8);
```
