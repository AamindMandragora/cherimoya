# P020: A closure is written '(params) -> (outputs) { body }'

Topic: 2.12 Closures

A closure is its inputs in parentheses, `->`, its outputs in parentheses if they're written, and its body. In prefix position, a parenthesized list followed by `->` is always a closure, since `->` has no other expression meaning.

## No Example

A parameter list that doesn't close properly is reported as a parameter list first, so this error only ever follows that one.
