# P029: A subjectless match's arms are '(condition)' or '_'

Topic: 3.6 `match`

A match without a subject has nothing to compare a pattern with, so each arm is a guard, a condition in parentheses, or `_`.

## Wrong

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match {
        1 -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> f -> (r :: int) {
    match {
        (n = 1) -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
