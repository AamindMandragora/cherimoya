# S009: Tests go in a .toya file

Topic: 12 Tests

Tests go in `.toya` files, so they never ship in a program. `cheri test` runs the tests in a `.toya` file, and `@test` anywhere else is an error. The fix is to move the test to a `.toya` file, or, as here, to drop `@test` and keep the function as an ordinary one.

## Wrong

```cherimoya
@test
let () -> adds -> () { assert (1 + 1 = 2); }
```

## Fixed

```cherimoya
let () -> adds -> () { assert (1 + 1 = 2); }
```
