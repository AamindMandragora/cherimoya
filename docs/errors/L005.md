# L005: A literal's characters have to be UTF-8

Topic: 1 Lexical structure

Source is UTF-8, and a character written as itself in a literal has to be valid UTF-8. A stray continuation byte, a sequence cut short, an overlong encoding, and an encoded surrogate are all errors, so every literal is valid UTF-8.

## No Example

This error only comes from bytes that aren't UTF-8, which can't be written on this page.
