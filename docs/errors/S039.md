# S039: Only a binding can be assigned

Topic: 3.3 Assignment and expression statements

The left side of an assignment has to be a place: a name, a field, an index, or a dereference. A function's name is none of these, since a function is declared once and never holds anything else.

To keep a value that changes, declare a binding with `mut` and assign to that.

## Wrong

```cherimoya
let () -> f -> () { }
let () -> g -> (r :: int) { f <- 1; 0 -| }
```

## Fixed

```cherimoya
let () -> g -> (r :: int) { let f :: mut <- 0; f <- 1; f -| }
```
