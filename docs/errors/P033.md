# P033: A sum's variant is a name with an optional payload

Topic: 5.1 Definitions

A sum is two or more alternatives joined with `|`, and each one is a variant: a name, with the types of its payload in brackets if it has one, like `Circle[f64]`.

## Wrong

```cherimoya
type Shape <- Circle[f64] | Rect[2, f64];
```

## Fixed

```cherimoya
type Shape <- Circle[f64] | Rect[f64, f64];
```
