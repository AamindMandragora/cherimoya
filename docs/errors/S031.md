# S031: Every yield to one scope has the same type

Topic: 3.4 Yields (`-|`)

A scope that isn't a function gets its type from what's yielded to it: the first yield sets it, and every later one has to agree, with a note at the first.

## Wrong

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        0 -> { 1 -| }
        _ -> { true -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> pick -> (r :: int) {
    match (n) {
        0 -> { 1 -| }
        _ -> { 2 -| }
    } -|
}
```
