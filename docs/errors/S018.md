# S018: An uninitialized binding is mutable

Topic: 4.8 Uninitialized storage

A binding made with `<- _` has no value yet, and assigning it later is the only way it gets one, so it has to be `mut`, or have `mut` elements, for an array.

## Wrong

```cherimoya
let () -> five -> (r :: int) {
    let x :: int <- _;
    5 -|
}
```

## Fixed

```cherimoya
let () -> five -> (r :: int) {
    let x :: mut int <- _;
    x <- 5;
    x -|
}
```
