# P015: A range's elements are unnamed

Topic: 2.6 Ranges

A name and `<-` inside a pack make a named element, which is a record's field. A range's values are its bounds and stride, which have no names, so a named one is an error, with a fix that removes the name.

## Wrong

```cherimoya
let (n :: int) -> small -> (r :: int) {
    match (n) {
        [lo <- 1, ..., 5] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> small -> (r :: int) {
    match (n) {
        [1, ..., 5] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
