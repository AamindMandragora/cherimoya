# S050: A conversion's value is unnamed

Topic: 2.4 Construction, conversion, and annotation

Calling a type converts or makes a value, and it takes one unnamed value. A conversion has no inputs to name, so a name in front of its value names nothing.

## Wrong

```cherimoya
let (x :: int) -> f -> (r :: i32) { i32(v <- x) -| }
```

## Fixed

```cherimoya
let (x :: int) -> f -> (r :: i32) { i32(x) -| }
```
