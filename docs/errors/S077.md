# S077: What an input can write is writable where it comes from

Topic: 4.6 Inputs and outputs

An input borrows what it's given, and can write it only where the input says so, like `peek mut int` or `arr[mut int]`. What it can write has to be writable where it comes from, so passing a binding never changes it unless the binding was declared to change.

## Wrong

```cherimoya
let (n :: peek mut int) -> bump -> () { n +<- 1; }
let () -> f -> (r :: int) { let x <- 1; bump(x); x -| }
```

## Fixed

```cherimoya
let (n :: peek mut int) -> bump -> () { n +<- 1; }
let () -> f -> (r :: int) { let x :: mut <- 1; bump(x); x -| }
```
