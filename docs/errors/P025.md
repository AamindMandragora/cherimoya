# P025: An assert is written 'assert (condition);'

Topic: 3.10 Verification statements

`assert (p);` is always enforced, with its condition in parentheses and a `;` after it.

## Wrong

```cherimoya
let (a :: int) -> f -> (r :: int) {
    assert (a > 0;
    a -|
}
```

## Fixed

```cherimoya
let (a :: int) -> f -> (r :: int) {
    assert (a > 0);
    a -|
}
```
