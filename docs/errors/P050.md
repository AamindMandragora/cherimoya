# P050: Index arguments are unnamed

Topic: 2.9 Indexing, slicing, dereference, views

`[...]` after a value indexes, slices, dereferences, or instantiates, and none of those take named arguments, so a name and `<-` there is an error, with a fix that removes it.

## Wrong

```cherimoya
let xs <- [1, 2];
let y <- xs[i <- 0];
```

## Fixed

```cherimoya
let xs <- [1, 2];
let y <- xs[0];
```
