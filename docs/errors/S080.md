# S080: start is declared the way the runtime calls it

Topic: 6.4 Programs and the top level

The runtime calls `start` with no inputs and uses its result as the exit code, so it's declared `let () -> start -> (code :: int)`.

## Wrong

```cherimoya
let () -> start -> () { }
```

## Fixed

```cherimoya
let () -> start -> (code :: int) { 0 -| }
```
