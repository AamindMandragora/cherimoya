# S047: An operator only takes the types it works on

Topic: 5.5 Integers

Each operator works on some types: arithmetic and comparisons take numbers, bitwise operators take integers, and logical operators take bools and boolfs. Nothing converts to fit an operator, so an operand of another type is an error.

## Wrong

```cherimoya
let (x :: bool) -> f -> (r :: bool) { -x -| }
```

## Fixed

```cherimoya
let (x :: bool) -> f -> (r :: bool) { !x -| }
```
