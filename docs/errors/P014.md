# P014: A range has one '...', at most two values before it and one after, and a bound

Topic: 2.6 Ranges

A range is a pack with `...` in it. `...` is a pack element, not an operator, and a range has exactly one, at most two values before it, which give its start and stride, and at most one after, its end. `[...]` alone has no bound at all.

## Wrong

```cherimoya
let (n :: int) -> small -> (r :: int) {
    match (n) {
        [1, ..., 5, ...] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```

## Fixed

```cherimoya
let (n :: int) -> small -> (r :: int) {
    match (n) {
        [1, ..., 5] -> { 1 -| }
        _ -> { 0 -| }
    } -|
}
```
