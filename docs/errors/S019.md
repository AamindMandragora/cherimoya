# S019: A binding holds a value

Topic: 3.2 Bindings

A call to a function that yields nothing, `void`, has no value to bind. It's written as a statement of its own instead.

## Wrong

```cherimoya
let () -> nothing -> () { }
let () -> run -> () { let x <- nothing(); }
```

## Fixed

```cherimoya
let () -> nothing -> () { }
let () -> run -> () { nothing(); }
```
