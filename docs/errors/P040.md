# P040: An address type takes only the type it names, 'addr[T]'

Topic: 2.9 Indexing, slicing, dereference, views

An address, `addr[T]`, says which place a value is in, for identity. It can't be read or written through, so it holds nothing, and unlike `arr` it takes no size and no allocator.

## Wrong

```cherimoya
let (a :: addr[3, int]) -> f -> () { }
```

## Fixed

```cherimoya
let (a :: addr[int]) -> f -> () { }
```
