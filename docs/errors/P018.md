# P018: A refinement is written 'T {predicate}'

Topic: 5.2 Refinements

A refinement is a predicate in braces after its type, `a :: int {a >= 0}`, and ends with `}`.

## Wrong

```cherimoya
let (a :: int {a >= 0) -> f -> (r :: int) { a -| }
```

## Fixed

```cherimoya
let (a :: int {a >= 0}) -> f -> (r :: int) { a -| }
```
