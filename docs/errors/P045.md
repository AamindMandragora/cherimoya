# P045: The left side of an assignment is a place

Topic: 3.3 Assignment and expression statements

A statement starts with an expression, and a `<-` after it makes it an assignment, so the expression must be a place: a name, a field, an index, a dereference, or `_`.

## Wrong

```cherimoya
let x :: mut int <- 1;
x + 1 <- 2;
```

## Fixed

```cherimoya
let x :: mut int <- 1;
x <- 2;
```
