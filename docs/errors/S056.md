# S056: Making an array or a handle takes the values its kind takes

Topic: 4.3 Arrays and handles

`ptr[T](v)` takes the one value it puts on the heap, `arr[T](xs)` takes the one fixed array or string it's made from, and `arr[n, T](...)` takes nothing, a fill, or `_`.

## Wrong

```cherimoya
let () -> f -> (r :: int) { let p <- ptr[int](); p[] -| }
```

## Fixed

```cherimoya
let () -> f -> (r :: int) { let p <- ptr[int](1); p[] -| }
```
