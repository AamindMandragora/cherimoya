## Covers

- Inside: values and rules, where the same program with the same inputs always does the same thing
- Outside: the hardware, the OS, files, the network, other programs, where things fail
- Exit codes and traps are the first ways the inside reaches the outside
- Why the line matters: everything inside can be checked before the program ever runs
