# Who Owns What

Outline, not yet written.

## Covers

- Heap memory has to be given back, and the owner is the one that gives it back
- Moving hands ownership over, and a moved value can't be used again
- Views: `peek` lends a value without handing it over
- Addresses: `addr x` names where a value lives, and can't outlive it
- Why this needs no garbage collector and no lifetimes
