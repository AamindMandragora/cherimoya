## Covers

- Fixed-width arrays, `arr[3, int]`, literals and indexing
- Indexes start at 0, and indexing past the end traps
- Arrays whose length is only known at run time live on the heap, `arr[int](n)`
- Pointers, `ptr[T]`, one value on the heap
